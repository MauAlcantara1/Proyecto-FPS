# 

## Descripción

Proyecto de videojuego FPS desarrollado en Unity como proyecto académico.


---

# Características

## Movimiento del jugador

- Movimiento FPS en primera persona.
- Soporte para:
  - Teclado y mouse.
  -  Control Xbox mediante Input System de Unity.
- Sistema de:
  - Caminar.
  - Correr.
  - Saltar.
  - Gravedad usando CharacterController.

## Cámara

- Cámara FPS con control de:
  - Mouse.
  - Stick derecho del mando.
- Rotación independiente:
  - Movimiento horizontal del jugador.
  - Movimiento vertical de la cámara.
